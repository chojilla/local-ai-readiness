How do I find my computer specifications?

Windows: Open Settings → System → About to find installed RAM and processor. Open Task Manager → Performance → GPU for graphics information. Open File Explorer → This PC for free storage.

Mac: Apple menu → About This Mac for chip and memory. System Settings → General → Storage for free space. Apple Silicon uses shared memory, so you do not need to know dedicated VRAM.

Still unsure? Leave the uncertain answers as “Not sure.” The checker will recommend a small trial rather than assume you have a powerful GPU.

RAM = your computer's working memory. GPU = graphics processor, sometimes used to accelerate AI. VRAM = memory on a dedicated graphics card. SSD = storage space used to download models. You do not need to memorize these terms.

2. Which software does what?

Ollama

Local model runner and command-line/API workflow. Excellent for reproducible exercises and integration with other interfaces.

Official website

LM Studio

Graphical desktop app for downloading, chatting with and serving compatible local models. Convenient for nontechnical users and document experiments.

Official website

Strata

Advanced, evolving inference option focused on running very large models with memory offloading. Treat compatibility, supported formats and performance as experimental; confirm against current project documentation.

Project repository
Two things to choose: The application (Ollama, LM Studio, Strata) is how you run AI on your computer. The model (Qwen, Gemma, Llama, Phi) is the AI that answers questions. Most beginners should choose an application first, then try a small model. You do not need to compare every family.

Meet the model families

Qwen — recommended starting point

Alibaba's family of open-weight AI models, with smaller versions suitable for ordinary laptops and larger versions for demanding writing, coding, and analysis. A sensible first choice for the course, but outputs still require source checking.

Qwen models in OllamaQwen model documentation

Gemma

Google's open-weight model family. Useful as a second opinion when comparing writing quality, reasoning, and summarization. Available in multiple sizes; some releases have different text, image, or context capabilities.

Beginner-friendly Gemma overviewBrowse Gemma in Ollama

Llama

Meta's widely used open-weight model family, supported by many local AI applications. A useful comparison model with a large community and many tutorials. Check the license and exact version; model sizes and requirements vary considerably.

Llama overviewBrowse Llama in Ollama

Phi

Microsoft's compact-model family, designed to provide useful capabilities with relatively modest model sizes. Worth trying when memory or speed is limited, although smaller models can struggle with complex manuscript critique.

What about other models, and what do “4B” or “quantized” mean?

Other families include Mistral and DeepSeek, but beginners do not need to evaluate every option. A label such as 4B means roughly four billion model parameters, not 4 GB of RAM. Quantization compresses a model to use less memory, sometimes at a quality trade-off. A bigger model is not automatically more accurate for your task.

For more models, browse the Ollama model catalog or Hugging Face model directory. Check release details, licensing, and hardware requirements before downloading.

3. Faculty manuscript-review exercise

Choose a publicly available, non-confidential manuscript or synthetic example. Compare two locally available models using the same prompt and evaluate accuracy against the source document.

Suggested prompt: “Act as a critical peer reviewer. Using only the supplied manuscript text, identify the research question, study design, three strengths, five substantive limitations, and any claims not adequately supported by the results. Quote short supporting passages or identify sections where possible. Distinguish observed facts from inferences. If information is absent, say so. Do not invent references.”

Check whether the app actually extracted the full PDF, including tables and figures. A larger model does not automatically have access to more document content. For a fair comparison, use the same extracted text and context settings.

4. Responsible use in clinical practice

Do not upload identifiable patient data or confidential hospital documents unless your institution has specifically authorized the full local workflow. “Local” is not a substitute for security review. Confirm where prompts, chat histories, telemetry, updates and document indexes are stored, and whether network access is disabled.

Models can hallucinate citations, misinterpret tables and omit diagnostic considerations. Verify all clinical or scientific conclusions against primary sources.
